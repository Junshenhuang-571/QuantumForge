QuantumForge

A quantum-computation kernel in Rust — exact-rational analytic core, CPU simulator, interactive REPL, and optional CUDA / LLVM backends, all sharing one set of semantics.

Rust Exact-Rational CUDA LLVM JIT 136 Tests GPL-3.0

Install & Run

# Install from crates.io
cargo install quantumforge

# Or build from source
git clone https://github.com/Junshenhuang-571/QuantumForge.git
cd QuantumForge
cargo run --bin qf
View on GitHub crates.io docs.rs

Try It — Interactive REPL

The qf REPL lets you build circuits incrementally, draw them as ASCII diagrams, run and measure them, and run variational algorithms (VQE, QML training).

qf> qubits 3
qf> add H[0]
qf> add CNOT[0,1]
qf> add Ry[Pi/4,2]
qf> draw
q0 ───H──────•──────────
q1 ──────────⊕──────────
q2 ──────────────Ry0.79─
legend: ─ wire  • control  ⊕ target(X)  │ span  x swap  M measure
qf> run
qf> measure

Features

Exact-Rational Core

PauliSum / ExactComplex / Rational do exact rational arithmetic — VQE converges to the exact ground-state energy to machine precision.

Interactive REPL

Live state, draw renders real circuit diagrams with vertical connectors, measure gives seeded reproducible shots.

Density Matrices

Noise channels (depolarizing / amplitude / phase damping), partial trace, purity tracking, maximally-mixed states.

Variational / QML

ParameterizedCircuit with data encoding, adjoint + parameter-shift gradients, Adam trainers for regression and classification.

CUDA Backend

NVRTC device-resident state vectors, density matrices, batched shots — validated against the Rust reference.

LLVM JIT

Lower scalar expressions to LLVM IR and runtime-JIT for fast exact evaluation.

Library Usage

use quantumforge::{Circuit, StateVector, parse_circuit};

// Build from a Wolfram-style expression, or the builder API.
let circuit = parse_circuit("Circuit[H[0], CNOT[0,1], Measure[0,0]]").unwrap();
let initial = StateVector::zero(2).unwrap();
let result = circuit.run_shots(&initial, 1000, 42).unwrap();
println!("{:?}", result.counts);
